# Closest-Review Gap Matrix

This matrix is maintained to prevent novelty claims based on incomplete awareness of recent reviews.

| Recent review direction | What it already contributes | What the Observatory review must add rather than repeat |
|---|---|---|
| Integrated MANET review (routing + security + energy + intelligent methods, 2000–2025) | broad thematic integration and literature-level performance synthesis | machine-readable claim context; explicit comparability classes; implementation status; controlled evidence kept separate from published values; failure/ranking frontiers |
| PRISMA-guided MANET evaluation/reproducibility review (2020–2025) | evaluation orientation, reporting completeness, reproducibility diagnostics | protocol/mechanism atlas spanning the historical field; per-algorithm status cards; executable benchmark admission; contradiction and capability-gap tracking |
| Decision-centered learning-routing survey (2026) | learner role/authority/state/horizon taxonomy; 92-paper corpus; 37-paper evaluation audit | integrate classical-to-learning routing in one evidence ontology; controlled classical/modern benchmark; status and gap maps across all routing families |
| Classical routing surveys | protocol classes and descriptive comparisons | evidence provenance, scenario-conditioned claims, modern learning/security/energy continuum, reproducibility and benchmarkability |
| Heterogeneous-network performance reviews | selected protocol comparisons under heterogeneity | systematic evidence coverage and condition-dependent frontier analysis rather than one scenario family |

## Novelty test before paper submission

A contribution is retained only if at least one of the following holds:
1. no closest review provides it;
2. a closest review provides a narrative version but not a reproducible/machine-readable version;
3. the Observatory provides controlled evidence where prior work provides only heterogeneous literature synthesis;
4. the Observatory resolves a documented contradiction;
5. the Observatory turns an open question into a falsifiable benchmark obligation.

No statement such as "first ever", "no review exists", or "most comprehensive" is used without a documented search supporting it.
