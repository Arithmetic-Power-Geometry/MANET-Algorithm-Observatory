# Journal Decision Gate

## Decision timing

The target journal is selected only after:
- literature corpus freeze;
- closest-review non-redundancy audit;
- controlled benchmark completion;
- final contribution type is known;
- final figure/table set exists;
- manuscript length can be estimated accurately.

## Route A — IEEE Communications Surveys & Tutorials

Use this route if the dominant contribution is a comprehensive, tutorially useful survey/evidence atlas that:
- covers MANET routing development from foundational mechanisms to current intelligent routing;
- establishes clear non-redundancy against recent surveys;
- integrates taxonomy, evidence maturity, comparability, reproducibility, contradictions and research obligations;
- uses controlled Observatory evidence to resolve or illustrate literature-level problems without allowing experiments to displace the survey/tutorial mission;
- can be compressed to the current initial-submission page constraint.

Working architecture: COMST-capable.

## Route B — Ad Hoc Networks

Use this route if the dominant contribution becomes:
- MANET-specific controlled experimental evidence;
- protocol performance under mobility/propagation/load/scale changes;
- ranking stability and failure frontiers;
- reproducible MANET benchmarking;
- a capability-gap-driven new routing method.

This is the strongest direct specialist-scope route currently identified.

## Route C — Computer Networks

Use this route if the dominant contribution becomes:
- networking methodology;
- benchmark/reproducibility infrastructure;
- routing performance evaluation;
- reusable open-source research software plus substantive networking results.

## Decision variables

Record at freeze:
1. dominant contribution type;
2. breadth of literature synthesis;
3. strength of non-redundancy case;
4. amount of original controlled evidence;
5. presence/absence of a novel routing algorithm;
6. reproducibility/software contribution;
7. final double-column length;
8. current journal scope and article type;
9. current indexing/quartile/metrics from authoritative sources;
10. publication model/cost constraints if relevant.

## Current strategy

Build the project to the methodological and presentation standard required for a demanding communications survey. Do not distort the science merely to fit a journal selected too early.
