# IEEE COMST LaTeX Preparation Source

## Official template source

For manuscript preparation, use the IEEE Author Center **IEEE Template Selector** and select the journal/publication requested by the selector. Do not rely on an arbitrary third-party ZIP stored in this repository.

Official IEEE Author Center template page:
https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/authoring-tools-and-templates/tools-for-ieee-authors/ieee-article-templates/

Official IEEE Author Center authoring tools:
https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/authoring-tools-and-templates/tools-for-ieee-authors/

COMST-specific author policy:
https://www.comsoc.org/publications/journals/ieee-comst/policies-guidelines

## Project rule

At paper-writing freeze:
1. re-open the official IEEE Template Selector;
2. select the current IEEE journal LaTeX package applicable to IEEE Communications Surveys & Tutorials;
3. download a fresh copy;
4. record template retrieval date/version/checksum;
5. compile the manuscript from that frozen template;
6. re-check COMST's current submission policy immediately before submission.

Do not copy IEEE template/class files into the Apache-2.0 Observatory repository unless their redistribution terms are separately verified. The research repository and manuscript package remain separate artifacts.

## Current COMST preparation constraints

- planned article category: Survey;
- tutorially readable to communications generalists;
- comprehensive literature coverage;
- initial manuscript designed for the current 30-page double-column ceiling;
- manuscript claims governed by the Observatory evidence-to-claim gate.
