# Artifact Manifest

This repository retains only evidence and analysis artifacts supported by the implemented review and controlled benchmark.

## Literature and evidence artifacts

The literature layer includes:

- the master study registry;
- structured evidence records;
- comparability and maturity mappings;
- implementation limitations;
- contradiction records;
- research obligations;
- reference and source registries.

## Controlled S2 artifacts

The S2 benchmark supports:

- scenario-level packet-delivery-ratio summaries;
- paired protocol effects with seed-level uncertainty;
- strict rank-1 membership summaries;
- zero-delivery incidence;
- BASE, FAST, LOAD, and SCALE contrasts.

The S2 design does **not** by itself support a continuous failure frontier, a propagation-sensitivity surface, a validated routing-cost frontier, or a universal protocol ranking. Those claims require additional controlled dimensions and are therefore not treated as completed repository findings.

## Provenance

Controlled evidence is tied to explicit scenario definitions, metric definitions, implementation identity, seed control, ns-3.47 configuration, workflow execution, and versioned analysis outputs.
