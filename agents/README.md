# Evidence Mining Agents

Agents are research workstreams, not autonomous sources of truth.

Each family agent populates the shared master registry and evidence schema. Discovery may use reviews, citation chains, databases, standards, or repositories, but substantive claims require V2+ verification.

## Required family output

- discovery list
- verified primary-study list
- mechanism variants
- strongest relevant baselines
- implementation candidates
- scenario/evaluation coverage
- contradiction candidates
- evidence maturity profile
- unresolved research obligations
- benchmark-admission recommendation

## Completion rule

Complete means evidence saturation for the scientific questions: defining work, major variants, representative recent work, strongest reproducible evidence, contradictory/negative evidence, and relevant adjacent-domain transfer evidence have all been actively sought.
